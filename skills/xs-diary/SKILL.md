# 毎日の日記記録スキル

1日を日記形式で `notes/` に記録する。Notion保存とGit同期は任意。

## 絶対遵守事項

- **日常の出来事（食事・家族・ペット・散歩・仕事の感想）は必ず記録する**
- 日常セクションを開発作業セクションより**上に配置**する
- ファイル操作なしに「記録した」と報告しない（嘘禁止）
- 完了報告には**Notion日記のURL**を含める（Notion連携時）
- 記録にない数値を断定しない。推定する場合は「推定」と明記する
- チャット履歴、memory、notes、必要ならxangi-searchまたは通常のファイル検索で漏れを拾う

## 保存先

| 場所 | 用途 |
|------|------|
| `notes/YYYYMMDD_diary.md` | 日記本体 |
| `memory/YYYYMMDD.md` | 参考資料（会話ログ・調べたこと） |
| **Notion日記DB**（任意） | 画像・動画付きリッチ版 |

## 手順

### Step 1: 情報収集

1. `memory/YYYYMMDD.md` を読む（その日の出来事・会話ログ）
2. `date -d "YYYY-MM-DD" +%A` で**曜日を確認**（思い込みで書かない）
3. 必要に応じて `notes/` やxangi-searchで、その日の関連メモ・発信・作業ログを確認する。xangi-search未導入時は通常のファイル検索を使う
4. チャットプラットフォームで動いている場合は、直近履歴や添付ファイルも確認する

### Step 2: notes/に日記作成

`notes/YYYYMMDD_diary.md` を作成。

### Step 3: Notion日記ページ作成（任意）

Notion連携が設定済みで、ユーザーがその保存先への送信を許可している場合だけ、`skills/xs-notion-manager/SKILL.md` を読み、現行のコマンドで保存する。未設定でもローカル日記は完了できる。

### Step 4: 保存確認と任意の同期

`notes/YYYYMMDD_diary.md` を読み戻し、日付・内容・保存先を確認する。日次記録へ保存先を追記した場合は、その追記も確認する。

Git同期は `skills/xs-note-taking/SKILL.md` の任意同期手順に従う。既定のGit対象外設定を変更したり、個人記録を強制追加したりしない。Notionの保存結果はローカル保存と区別して報告する。

### Step 5: 完了報告

```
MM/DDの日記完了！

保存先: notes/YYYYMMDD_diary.md
Notion日記: https://www.notion.so/xxx（保存成功時のみ）

やったこと：
- ...
```

## notes/ フォーマット

```markdown
---
tags: [diary]
---

# YYYYMMDD (曜日)

## タイムライン
- HH:MM 出来事

## 食事
- 朝:
- 昼:
- 夜:

## 気づき・学び

## 開発作業

## 気分・体調

## 明日の予定
```

**セクション順序**: 日常（タイムライン・食事） → 開発 → その他

## 書き方の方針

- 事実と感想を分ける
- 食事・運動・睡眠・家族・ペット・外出など、生活ログを開発ログに埋もれさせない
- 数値は記録から直接拾えるものを優先する
- 写真や添付がある場合は、見た内容を短く記録する
- 技術作業は、PR番号・commit・検証結果・次の課題を1〜3行でまとめる

## 日付ルール

- **0時〜朝5時の作業** → 前日の日記に記録（寝るまでが1日）

## 完了前チェックリスト

```
□ `date` コマンドで曜日を確認した
□ 日常セクションに食事・家族・ペット・散歩・仕事を記録した
□ 日常セクションが開発より上にある
□ notes/の日記を読み戻した（memory/へ追記した場合は追記も確認した）
□ 投稿文は日本語のみ、作業ログ混入なし
□ 推定値と実測値を混同していない
```
