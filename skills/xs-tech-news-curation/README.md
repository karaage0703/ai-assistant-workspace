# テックニュースキュレーション

RSSからAI・技術ニュースを探し、記事本文を確認して要約します。3〜5件を目安に紹介し、その中から特に注目する1〜2件について、実務で役立つ場面や従来との違いを説明します。

## 使い方

- 「テックニュースをまとめて」
- 「Pythonのニュースを日本語の記事だけで教えて」
- 「このRSSから、開発ツールのニュースを選んで」

出力は記事の要約・公開日・リンクと、注目記事の選定理由です。特定のチャットサービスや個人向けフィードの設定は必要ありません。

## 必要なもの

RSSと記事本文を取得できるWebツール、またはcurlなどのHTTP取得手段を使います。[SKILL.md](./SKILL.md)のシェル例はBash、curl、mktemp、sedを使用します。取得後のRSS/Atomの候補抽出や本文確認は、利用環境の読み取り・解析ツールで行います。

検索拡張や外部AIは必須ではありません。フィードを指定しなければ、SKILL.md記載の公開フィードを候補にします。

## 取得できない場合

- HTTPエラー・空応答・RSS/Atom以外の応答は成功扱いしません。保存途中のファイルも使いません。
- 別フィードやWeb検索で補完し、確認できた件数だけ紹介します。
- 本文を読めない記事は原則差し替えます。指定記事などを残す場合は「本文未確認・概要のみ」と表示し、注目記事には選びません。
- 認証の回避や依存ツールの自動導入は行いません。

SNSや別チャンネルへの送信は含みません。通常は依頼された会話への返信で完了します。詳しい選定・確認手順は[SKILL.md](./SKILL.md)を参照してください。
